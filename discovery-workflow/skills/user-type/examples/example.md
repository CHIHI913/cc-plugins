# ユーザータイプ（見本: CookPal）

## 軸の定義

- **横軸** 料理への負担感（低い ←→ 高い）。3要因: 時間制約・スキル不足・家族の制約（好き嫌い・アレルギー等）
- **縦軸** 改善意欲の顕在/潜在（潜在 ←→ 顕在）。新しいツール・方法を試す意欲の強さ

## ユーザータイプマップ

```
         改善意欲 顕在（積極的に改善したい）
                 │
    ┌────────────┼────────────┐
    │            │            │
    │  ③ 探求型  │ ① 切迫型   │
    │ 料理を楽し │ 毎日の献立 │
    │ みつつ効率 │ に追われて │
    │ 化したい   │ いる       │
負担感 低い──────┼────────負担感 高い
    │            │            │
    │  ④ 無関心型│ ② 諦め型   │
    │ 現状に     │ 外食・惣菜 │
    │ 不満なし   │ に依存     │
    │            │            │
    └────────────┼────────────┘
                 │
         改善意欲 潜在（現状維持でよい）
```

## 各タイプ詳細

| タイプ | 特徴 | 行動パターン | コアの価値 |
|--------|------|-----------|----------|
| ① 切迫型 | 負担感高い×改善意欲顕在。「毎日が戦場」。共働き×子育てで時間がない | 帰りの電車でレシピ検索→冷蔵庫を見て絶望→とりあえず作る。レシピアプリ複数利用（10名中7名） | AI食材認識→即レシピ提案 + 栄養自動計算で「考える時間ゼロ」 |
| ② 諦め型 | 負担感高い×改善意欲潜在。料理をあきらめかけている | 惣菜・冷凍食品・外食に依存。罪悪感はあるが改善する気力がない | 超簡単レシピ（3ステップ以内）、成功体験の積み重ね |
| ③ 探求型 | 負担感低い×改善意欲顕在。料理が好きで効率化にも興味がある | SNSでレシピ収集、アレンジを自ら考える。情報発信も行う | アレンジ共有・レビュー機能、コミュニティでの承認 |
| ④ 無関心型 | 負担感低い×改善意欲潜在。全員のスタート地点 | 決まったメニューをルーティンで回している。特に不満なし | 負荷のかからない気づき（「この食材でこんな料理も作れますよ」） |

## 遷移パス

```
④ 無関心型 ──(負担感の増加)──→ ② 諦め型 or ③ 探求型

② 諦め型 ──(成功体験・きっかけ)──→ ① 切迫型
③ 探求型 ──(負担感の増加)──→ ① 切迫型
```

遷移トリガー
- ④→②: 子供の誕生・共働き開始による時間制約の急増
- ②→①: 子供の健康診断で栄養指摘、食費の高騰で外食・惣菜を減らしたい
- ③→①: 第二子誕生・異動による時間制約の増加。料理を楽しむ余裕がなくなる

## ソリューション仮説

| タイプ | ソリューション |
|--------|------------|
| ① 切迫型 | AI食材認識→即レシピ提案をメイン体験。冷蔵庫の写真を撮る→15分レシピが3品出る→栄養バランスも自動表示。「考える時間ゼロ」 |
| ② 諦め型 | 超簡単レシピ（3ステップ・5分以内）から始める低ハードル体験。「今日はこれだけ作ってみませんか？」のプッシュ通知で①への遷移を促す |
| ③ 探求型 | アレンジ共有・レビュー機能でコミュニティの中心に。質の高いレシピコンテンツとアレンジのディスカバリー |
| ④ 無関心型 | パッシブな食材活用提案。冷蔵庫の食材登録だけしておけば「この食材、明日が賞味期限です。こんなレシピはどうですか？」と通知 |
