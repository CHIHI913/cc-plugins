# SWOT分析 ガイド

## このガイドについて

SWOT分析とクロスSWOT分析の方法を解説する。テンプレートは [template.md](template.md) を使用。

## SWOT分析とは

自社の内部環境（強み・弱み）と外部環境（機会・脅威）を整理し、戦略の方向性を導出するフレームワーク。

**目的**: 抜け漏れなく視点を洗い出し、プロダクトをつくるための環境を深く理解する
**インプット**: PEST分析（O/Tへ）、自社の強み・弱みの棚卸し
**アウトプット**: 4つの戦略方向性（積極/改善/差別化/防衛）

> フレームワークの目的は「きれいに分析すること」ではなく、**視点の漏れをなくすこと**。

## ディスカバリーワークフローにおける位置づけ

```
PEST分析（外部環境）
    ↓ O（機会）・T（脅威）へ
【SWOT分析】◀ ここ
    ↓ 4つの戦略方向性
クロスSWOT分析
    ↓
STP分析（ターゲット・ポジショニング）
```

## 記入のポイント

### O（機会）/ T（脅威）

PEST分析の結果から記載する。自社で新たに分析するのではなく、PEST分析で洗い出した外部環境要因を「機会」と「脅威」に分類する。

### S（強み）/ W（弱み）

内部環境として自社の強み・弱みを記載する。

**強みの見つけ方**:
- ユーザーインタビューで評価されたポイント
- 競合にはない独自のリソース・ケイパビリティ
- 既存の顧客基盤やデータ

**弱みの見つけ方**:
- ユーザーインタビューで指摘された課題
- 競合と比較して劣っている点
- リソースの制約

> **コダックの教訓**: 自社の強みに対する「偏見」が機会喪失につながる。強みだと思い込んでいるものが、環境変化で弱みに転じることがある。

### 記載順序

S/W/O/T各要素は、影響度が大きいものから順に記載する（番号が若い = 影響度が大きい）。

### 裏付けの重要性

各要素にはデータ・インタビュー引用・市場データなどの裏付けを併記する。「なんとなくの感覚」ではなく、根拠のある分析にする。

## クロスSWOT分析

SWOTの4要素をかけ合わせて、4つの戦略方向性を導出する。

```
           S（強み）         W（弱み）
O（機会）  積極戦略          改善戦略
           強みで機会を      弱みを克服して
           最大化            機会を活かす

T（脅威）  差別化戦略        防衛戦略
           強みで脅威に      弱み×脅威の
           対抗              リスクを最小化
```

| 戦略 | 問い | 優先度 |
|------|------|--------|
| **積極戦略**（S×O） | 強みを活かして、この機会をどう掴むか？ | 最優先 |
| **改善戦略**（W×O） | この弱みを克服すれば、機会を活かせるか？ | 中 |
| **差別化戦略**（S×T） | 強みを武器に、脅威にどう対抗するか？ | 中 |
| **防衛戦略**（W×T） | 最悪のシナリオにどう備えるか？ | リスク管理 |
