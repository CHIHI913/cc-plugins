# 競合分析 ガイド

## このガイドについて

競合分析の方法を解説する。テンプレートは [template.md](template.md) を使用。

## 競合分析とは

競合・代替品のWho-What-How（誰に・何を・どうやって）を整理し、自社の差別化ポイントを特定するフレームワーク。

**目的**: 競合の戦略を理解し、自社が勝てるポジションを見つける
**インプット**: 市場調査、STP分析
**アウトプット**: 差別化ポイント、ポジショニングへのインプット

## ディスカバリーワークフローにおける位置づけ

```
PEST → SWOT → STP
                 ↓
          【競合分析】◀ ここ
                 ↓
          ポジショニングマップ確定
                 ↓
          リーンキャンバス / ブランドコンセプト
```

## 分析のステップ

### Step 1: 競合・代替品のリストアップ

**直接競合**: 同じ課題を同じ方法で解決しようとしているサービス
**代替品**: 同じ課題を別の方法で解決しているもの（ツール、行動パターン含む）

> 代替品を見落としがち。ユーザーが「今どうやって対処しているか」を考えると代替品が見つかる。

### Step 2: Who-What-How 分析

各競合について3つの観点で整理する。

| 観点 | 問い |
|------|------|
| **Who** | どのようなユーザーをターゲットにしているか？ |
| **What** | どのような課題を解決しようとしているか？ユーザーへの約束は？ |
| **How** | どのように解決しようとしているか？独自の仕組みは？ |

> **Howだけの事例を集めない**。機能一覧を集めるだけでは不十分。「なぜその機能を選んだか（Who-Whatとの整合性）」まで踏み込む。

### Step 3: 機能比較マトリクス

機能カテゴリごとに、自社と競合の提供状況を ○/△/× で比較する。

### Step 4: 差別化分析

マトリクスから4つのレベルに分類：

| レベル | 意味 | 戦略的意味 |
|--------|------|----------|
| **自社のみ** | 独自機能 | 最大の差別化要因。維持・強化 |
| **自社 + 少数** | 差別化ポイント | 競合が追随する前に優位を固める |
| **多数が提供** | コモディティ | 差別化にはならない。最低限対応 |
| **自社にない** | Gap | 対応すべきか判断が必要 |

### Step 5: 競合の戦略意図を推測

自社が競合のPMになったつもりで、「なぜその解決策を選んだか」を考える。

- 競合が取ったリスクは何か？
- 競合が意図的に捨てたものは何か？
- 競合の成長戦略はどこに向いているか？

> リーンキャンバスを使って競合のビジネスモデルを分析するのも有効。

## 注意点

- **競合分析に時間をかけすぎない**: 目的はあくまで自社の差別化ポイントの特定
- **機能の数で勝負しない**: 「何があるか」より「何が独自か」が重要
- **定期的に更新**: 競合も進化する。四半期ごとの見直しを推奨
