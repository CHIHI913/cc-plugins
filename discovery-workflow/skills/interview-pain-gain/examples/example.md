### Q2-3: 料理で大変なこと【並び替え】

「大変だった順に並び替えてください」

| #   | 選択肢            |
| --- | -------------- |
| A   | 献立を決めること |
| B   | 食材の管理（在庫把握・使い切り） |
| C   | 調理の時間・手間 |
| D   | 栄養バランスの管理 |
| E   | 買い物（何を買うか・時間） |

回答
1. A. 献立を決めること
2. C. 調理の時間・手間
3. B. 食材の管理
4. D. 栄養バランスの管理
5. E. 買い物

- 1位の理由: 毎日「今日何作ろう」と考えるのが一番のストレス。冷蔵庫に何があるか正確に覚えていないし、帰りの電車で検索しても「これ作れるかな？」と不安になる。結局スーパーに寄ることになる
- 5位の理由: スーパーは帰り道にあるので寄ること自体は苦ではない。ただ、何を買えばいいかがわかっていないのが問題

## Q3: ニーズ（0:22〜0:32 / 10分）

### Q3-1: なぜレシピアプリを使うのですか？

「レシピアプリを使う一番の理由は何ですか？」

- レシピアプリを使う理由: レパートリーが少ないので、新しい料理を知りたい。でも実際は「鶏むね肉 簡単」みたいな食材検索ばかりで、新しい発見は少ない

### Q3-2: 冷蔵庫の中身を完璧に把握していたら？

「仮に、冷蔵庫の中身を完璧に把握し、それぞれの食材で何が作れるか全部知っているとします。その場合でもレシピアプリを使いますか？」

- [x] 使う → なぜ？: 作れるものはわかっても、栄養バランスや子供が食べてくれるかは別問題。他のお母さんがどうしているかも知りたい
- [ ] 使わない → なぜ？:

> [!NOTE] インタビュアーメモ
> 食材→レシピの変換だけでなく、「栄養」「子供の好み」「他の人の実体験」という追加ニーズが出てくるかに注目

### Q3-3: レシピアプリへの期待【2つ選択】

| #   | 選択肢      |
| --- | -------- |
| A   | 食材からのレシピ提案 |
| B   | 時短レシピの充実 |
| C   | 栄養バランス管理 |
| D   | 買い物リスト連携 |
| E   | 他ユーザーのアレンジ共有 |
| F   | 週間献立の自動生成 |

回答: 1. A. 食材からのレシピ提案 → 2. E. 他ユーザーのアレンジ共有

- 1位の理由: 冷蔵庫の中身をベースに「これ作れますよ」と提案してくれたら、毎日の献立決めのストレスがなくなる
- 2位の理由: 同じように共働きで子育てしている人が「うちではこうアレンジした」「子供がこれなら食べた」という情報がほしい。レシピ本より実体験のほうが信用できる

## Q4: レシピアプリ・AI活用状況（0:32〜0:40 / 8分）

「普段、レシピアプリやAI（ChatGPTなど）を料理で活用していますか？」

- [x] 既存アプリを使っている → Q4-1, Q4-2, Q4-3へ
- [ ] 使っていない → Q4-4へ

### Q4-1:（使っている場合）どのアプリをどう使っているか？

- [x] クックパッド（食材名で検索。人気順は有料なので新着順で見ている）
- [x] DELISH KITCHEN（動画で手順を確認。見ているだけで作らないことも多い）
- [ ] クラシル
- [ ] Kurashiru
- [ ] ChatGPT等のAI
- [ ] その他:

### Q4-2: 使っている中での不満

- [x] 検索結果が多すぎて選べない（クックパッドで「鶏むね肉」と検索すると何万件も出てくる）
- [x] 所要時間の表記が当てにならない（「15分」と書いてあるのに下準備を入れると30分かかる）
- [x] 冷蔵庫にある食材だけで作れるかわからない（レシピに載っている調味料がなかったりする）
- [ ] 有料機能が多い

### Q4-3: AIレシピ提案への期待

「もしスマホで冷蔵庫の写真を撮ったら、AIが中の食材を認識して15分以内のレシピを提案してくれるとしたら、使ってみたいですか？」

- 反応: すごく使いたい。毎日の「何作ろう」がなくなるなら最高。ただ、調味料まで認識できるのか？本当に15分で作れるのか？は気になる
- 追加で欲しいもの: 作った後に「うちの子は食べた/食べなかった」みたいなフィードバックを蓄積して、次回の提案に反映してほしい

> [!NOTE] インタビュアーメモ
> AI提案への期待は高いが、「信頼性」（本当に15分か、食材認識の精度）への懸念がセットで出てくるかに注目

## 気づき・示唆

1. 献立決めが最大のペイン。食材起点の提案が核心的なニーズ
2. 時短レシピの「所要時間の信頼性」が大きな不満。ユーザー投票による実時間の担保が差別化ポイントになりうる
3. レシピ情報だけでなく「同じ境遇の人の実体験」（アレンジ、子供の反応）への強いニーズがある
