# PEST分析 ガイド

## このガイドについて

PEST分析の方法を解説する。テンプレートは [template.md](template.md) を使用。

## PEST分析とは

外部環境を4つの視点（政治・経済・社会・技術）で整理し、市場全体で起きている変化と自社への影響を把握するフレームワーク。

**目的**: 「どんな流れが起きているか」「懸念点は何か」を洗い出す
**インプット**: 市場データ、統計情報、業界動向
**アウトプット**: SWOTのO（機会）・T（脅威）へのインプット

## ディスカバリーワークフローにおける位置づけ

```
【PEST分析】◀ ここ（Step 1: 外部環境分析）
    ↓ O（機会）・T（脅威）
SWOT分析（Step 2: 強みと弱みを分析）
    ↓
STP分析（Step 3: ターゲット・ポジショニング）
```

## 4つの視点

| 視点 | 問い | 分析のポイント |
|------|------|-------------|
| **P**（Politics） | 法規制や政策の変化は？ | 規制変化、労働法改正、補助金・助成金、業界団体の動向 |
| **E**（Economy） | 経済環境の変化は？ | 物価・賃金動向、市場規模推移、資金調達環境、為替 |
| **S**（Society） | 社会・生活の変化は？ | ライフスタイル変化、人口動態、働き方、価値観の変容 |
| **T**（Technology） | 技術の変化は？ | 技術革新、プラットフォーム変化、競合技術、普及率 |

## 記入のポイント

### 定量データを活用する

各要因には統計値・データを付記する。「なんとなく」ではなく根拠のある分析にする。

- 例: 「IT人材の転職率は前年比15%増（doda調査2025）」
- 例: 「生成AI利用率: ビジネスパーソンの42%が業務で活用（総務省2025）」

### 「プロダクトへの示唆」を書く

各要因を記載するだけでなく、「だからプロダクトにどう影響するか」を書く。分析を施策につなげるための鍵。

### 確実性 x 影響度で評価する

全要因を「確実性（高/低）」x「影響度（大/小）」で評価し、注力すべき要因を特定する。

| | 影響度 大 | 影響度 小 |
|---|---------|---------|
| **確実性 高** | 最重要（必ず対応） | 注視 |
| **確実性 低** | 要シナリオ検討 | 参考程度 |
