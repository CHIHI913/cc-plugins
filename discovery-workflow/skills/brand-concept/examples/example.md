# ブランドコンセプト（見本: CookPal）


## 背景（なぜ今このサービスが必要か）

共働き世帯は1,200万世帯を超え、夫婦ともに仕事と家事を両立する時代になった。しかし、毎日の献立決めと調理は依然として大きな負担であり、特に未就学児を持つ世帯では栄養バランスと時短の両立が切実な課題となっている。「冷蔵庫に食材はあるのに、何を作ればいいかわからない」「帰宅後15分で栄養のある食事を出したい」という声は構造的に存在する。
外部環境の変化（食費高騰・食品ロス削減の社会的要請・AI技術の成熟）がこの課題を加速させている。食費高騰で自炊ニーズは高まる一方、時間はない。冷蔵庫の食材を使い切れず廃棄する罪悪感もある。AI画像認識とレコメンド技術の進化により、「冷蔵庫の中身から最適なレシピを提案する」体験が技術的に実現可能になった今、この課題を解決するサービスが求められている。

## ターゲット

### 前提

共働き世帯（20〜40代）、特に未就学児を持つ子育て世帯

### 短期ターゲット: 献立の負担が最大化している層

**切迫型**: 未就学児の育児と仕事の両立で、毎日の献立決めが最大のストレスになっている層。離乳食・幼児食の栄養管理も加わり、「何を作ればいいかわからない」が日常化している。
基本的に調理に使える時間は15〜20分。帰宅後すぐに食事を出さなければならず、献立を考える余裕がない。冷蔵庫の食材は買ったものの使い切れずに廃棄してしまうことへの罪悪感も抱えている。

この層のニーズは**「冷蔵庫を開けたら、今日の献立がすぐわかる」体験**。食材認識から時短レシピ提案、栄養バランスの自動計算までをワンストップで提供することが求められる。

### 長期ターゲット: 自炊を習慣化したい層

**マンネリ型**: 自炊はしているが、同じメニューの繰り返しになっている層。共働きDINKsに多い。献立のバリエーション不足がストレスだが、新しいレシピを探す時間がない。
この層のニーズは**「手持ちの食材で、新しい発見がある」体験**。AI提案による意外な組み合わせや、他ユーザーのアレンジレシピが刺激になる。

**健康意識型**: 子どもの成長や自身の健康診断をきっかけに、栄養バランスを意識し始めた層。漠然と「栄養が偏っている気がする」と感じているが、栄養学の知識がなく具体的な改善方法がわからない。
この層のニーズは**「意識しなくても栄養バランスが整う」仕組み**。1週間の栄養追跡と、不足栄養素を補うレシピの自動提案が有効。

いずれの層も、ライフステージの変化（出産・育児開始・健康診断の結果等）で短期ターゲットへ遷移する可能性があり、その際の**第一想起**を狙う。

## プロミス（ユーザーへの約束）

CookPalは、毎日の献立に悩む共働き世帯に、冷蔵庫を撮るだけの手軽さで、AIが食材を認識し栄養バランスの取れた15分レシピを提案して、食卓のストレスを解消する。

## コアバリュー1: 冷蔵庫を撮るだけで、今日の献立が決まる（手軽）

本来時間と労力がかかる「食材の棚卸し→レシピ検索→献立決定」のプロセスを、AI食材認識によってワンアクションに圧縮する。

| 区分 | 項目 | 詳細 |
|:---:|------|------|
| ファクト | AI食材認識 | スマホカメラで冷蔵庫を撮影→食材を自動認識→レシピ提案。識別精度95%超 |
| ファクト | 15分以内の全レシピ保証 | 全レシピが15分以内で完成する設計。ユーザー調査「30分以内にしたい」62%を上回る |
| ファクト | 調理中音声アシスタント | 調理中はハンズフリーで手順を読み上げ。スマホに触れずに調理可能 |
| 仮説 | 食材の賞味期限管理 | AI食材認識と連動し、賞味期限が近い食材を優先的にレシピ提案。食品ロス削減に直結 |
| 仮説 | 1タップ買い物リスト | レシピに必要だが冷蔵庫にない食材を自動で買い物リストに追加。ネットスーパー連携も検討 |

## コアバリュー2: 家にある食材で、栄養バランスが自然に整う（栄養）

献立ごとの栄養素を自動計算し、1週間単位で栄養バランスを追跡。意識しなくてもバランスの取れた食事が実現する。

| 区分 | 項目 | 詳細 |
|:---:|------|------|
| ファクト | 栄養バランス自動計算 | レシピごとにカロリー・たんぱく質・脂質・炭水化物・主要ビタミンを自動算出 |
| ファクト | 1週間の栄養追跡ダッシュボード | 週単位で栄養バランスを可視化。不足している栄養素が一目でわかる |
| ファクト | 子育て世帯の栄養ニーズ | 子どもの食育への関心が過去最高。栄養バランスアプリ利用率20%超 |
| 仮説 | 不足栄養素の補完レシピ提案 | 「今週ビタミンCが不足しています」→ビタミンC豊富な食材を使った時短レシピを自動提案 |
| 仮説 | 年齢別の栄養基準対応 | 幼児・小学生・成人それぞれの推奨栄養量に基づいた献立提案 |

## コアバリュー3: 他のユーザーのアレンジで、レパートリーが自然に広がる（発見）

ユーザー同士のアレンジ共有とレビューにより、「同じ食材でもこんな作り方がある」という発見が日常的に生まれる。レシピのコモディティ化に対し、コミュニティの力で差別化する。

| 区分 | 項目 | 詳細 |
|:---:|------|------|
| ファクト | アレンジ共有機能 | オリジナルレシピに対するアレンジを投稿可能。「オリジナル→アレンジ」の派生関係を可視化 |
| ファクト | リアルレビュー | 「実際に15分で作れた」「子どもが食べた」等のリアルな評価。作る前の不安を解消 |
| ファクト | SNS映え文化との親和性 | Instagram「#おうちごはん」投稿2,000万件超。アレンジ投稿のモチベーションが外部にも存在 |
| 仮説 | 食材代替の自動提案 | 「この食材がない場合は○○で代替可能」をAIが自動提案。生成AIにより無限のバリエーション |
| 仮説 | コミュニティ発のレシピ品質認証 | 高評価アレンジレシピを「殿堂入り」として認定。プロ監修がなくてもレシピの質を担保 |

## ブランドパーソナリティ

親しみやすい・賢い・頼れる・楽しい
「忙しいあなたの、キッチンのパートナー」。押し付けず、食材から寄り添う提案をする。栄養も時短も、無理なく自然に。
