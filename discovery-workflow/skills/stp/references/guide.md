# STP分析 ガイド

## このガイドについて

STP分析（Segmentation / Targeting / Positioning）の方法を解説する。テンプレートは [template.md](template.md) を使用。

## STP分析とは

市場を細分化（S）し、狙うセグメントを選定（T）し、競合との差別化方向を定める（P）フレームワーク。

**目的**: 「誰に」「どんな価値を」「どう差別化して」提供するかを決定する
**インプット**: SWOT分析（戦略方向性）、VPC（ユーザー理解）
**アウトプット**: ターゲットセグメント + ポジショニング

## ディスカバリーワークフローにおける位置づけ

```
PEST分析 → SWOT分析
                ↓
         【STP分析】◀ ここ（Step 3）
                ↓

                ↓
         リーンキャンバス / ブランドコンセプト
```

## Segmentation（セグメンテーション）

### 軸の設計

市場を分ける軸を選ぶ。以下の分類軸から、プロダクトに適したものを選択する。

| 分類軸 | 例 |
|--------|-----|
| **デモグラフィック**（人口統計） | 年齢、性別、職業、年収、学歴 |
| **ジオグラフィック**（地理） | 地域、都市規模、気候 |
| **サイコグラフィック**（心理） | ライフスタイル、価値観、性格 |
| **行動変数** | 利用頻度、利用シーン、ブランドロイヤルティ |
| **ニーズベース** | 解決したい課題の種類、緊急度 |

> 2軸（横軸 x 縦軸）で4象限に分けるのが基本。軸は「ユーザーの行動や意思決定に影響する要因」を選ぶ。

### セグメント間の遷移

静的なセグメント分類だけでなく、**セグメント間の遷移パス**も設計する。

- どのセグメントが「入口」になるか
- どんなトリガーで次のセグメントに遷移するか
- プロダクトがその遷移をどう支援するか

## Targeting（ターゲティング）

### 6Rフレームワーク

セグメントを以下の6基準で評価し、ターゲットを選定する。

| 基準 | 問い |
|------|------|
| **Rank**（優先度） | 自社のビジョン・戦略に合致するか？ |
| **Realistic**（市場規模） | 十分な市場規模があるか？ |
| **Reach**（到達可能性） | ターゲットにリーチできるか？ |
| **Response**（反応測定） | 効果を測定できるか？ |
| **Rate**（成長性） | 今後の成長が見込めるか？ |
| **Rival**（競合状況） | 競合が少ない、または勝てる見込みがあるか？ |

### 短期 vs 長期ターゲット

すべてのセグメントに同時にアプローチするのではなく、短期と長期で分けて考える。

- **短期**: ニーズが顕在化しており、すぐにリーチ可能なセグメント
- **長期**: 潜在ニーズがあり、将来短期ターゲットに遷移する可能性があるセグメント

## Positioning（ポジショニング）

### ポジショニングマップの作り方

1. **競合分析を実施**: 競合のWho-What-Howを把握
2. **2つの軸を選択**: ターゲットにとって重要な評価基準で、かつトレードオフが存在する軸
3. **4象限マップを作成**: 競合と自社をプロット
4. **空白地帯を特定**: 競合がいないポジションを見つける

### 軸の選び方

**良い軸**: ターゲットの意思決定に影響し、競合間で差がつく
- 例: 「即時的な転職成果 <-> 中長期キャリア形成」
- 例: 「自走型（自分で探す）<-> 伴走型（プロが導く）」

**悪い軸**: 差がつかない、またはターゲットにとって重要でない
- 例: 「料金が安い <-> 高い」（差別化要因にならない場合）

### 各社の根拠

マップにプロットするだけでなく、各社がそのポジションにいる**根拠**を明記する。「なぜその位置か」が説明できなければ、ポジショニングの信頼性が低い。
